# QR Code Generator

A web-based QR Code Generator built with Python and FastAPI.
Generate QR codes for any URL or text instantly.

## Tech Stack
- Python
- FastAPI
- HTML & CSS

## Features
- Generate QR codes for any URL or text
- Download generated QR code as image
- Clean and simple UI

## How to Run

1. Clone the repository
   git clone https://github.com/arbaazmalik/QR-Code-Generator.git

2. Install dependencies
   pip install fastapi uvicorn qrcode pillow jinja2 python-multipart

3. Run the app
   uvicorn app:app --reload

4. Open browser
   http://localhost:8000
